## Cómo se hizo

- **Tokens.** Un script local, fuera del repositorio, firma en memoria un token del emisor de pruebas por petición (RS256 con la clave privada de `.secrets/test-issuer/`, que no está en el repositorio), con la forma de los de Entra y el `oid` y el correo del usuario E2E del perfil. Los usuarios E2E se sembraron con la misma SQL que el *global setup* (`e2e/support/e2e-users.ts`). curl recibe la cabecera `Authorization` por su entrada estándar (`-K -`): ningún token se escribe en disco, en este informe ni en la lista de procesos.
- **Qué se registra.** De cada llamada, el método, la ruta, el perfil, el código HTTP esperado y el obtenido, y el código del cuerpo de los errores. Este informe no reproduce cuerpos de petición ni de respuesta: las comprobaciones sobre campos las hace el script sobre la respuesta y aquí solo consta el veredicto.
- **El ejemplo de 1.850 €.** Es el de `finance/rebate-accrual` («A restated cost does not move a closed committed flight»), con cifras inventadas, trasladado a octubre porque el 26 de noviembre el stack solo puede cerrar hasta octubre: una línea `committed` de Adform en el canal Directo, 1.000.000 de impresiones contratadas a 5,00 €, extraprima plana del 25 % y la tarifa de plataforma del sistema, 1,00 €.
  - **Registro.** La campaña (`STEP12-EJEMPLO-…`) se registra por la API. La escala del 25 % se crea por la API para el grupo DEMO y el canal Directo, que ningún vuelo de la demo usa. La agencia DEMO no tiene tarifa de plataforma propia; la otra agencia sembrada tiene una de 1,10 € y daría 770 € de coste de plataforma.
  - **Vínculo.** El de Adform, con identificadores inventados, se escribe en la base: vincularlo por la API consultaría a Adform.
  - **Ingesta.** Las dos ingestas usan el servicio de ingesta real, `DeliveryIngestionService`, dentro del contenedor del backend y contra la base del stack. Un cliente de Adform inventado solo sustituye la llamada HTTP y sirve las filas.
    - La primera ingesta guarda 400.000 impresiones y 600,00 € el 10 de octubre, y 300.000 y 600,00 € el 28.
    - La segunda reexpresa el 28 con 800.000 y 2.400,00 €, es decir, 500.000 impresiones y 1.800,00 € más.
  - **Margen.** Cerrado con 700.000 impresiones y 1.200,00 €, el margen es 5.000,00 − 1.200,00 − 1.250,00 − 700,00 = 1.850,00 €. Con la entrega reexpresada sería 5.000,00 − 3.000,00 − 1.250,00 − 1.200,00 = −450,00 €.
- **El vuelo tardío.** Una segunda campaña de octubre (`STEP12-TARDIO-…`), registrada por la API después del primer cierre.
- **Orden.** Primero los rechazos de trading y business; después el ejemplo, el cierre, la reingesta y el vuelo tardío; al final, otra vez los rechazos, con el mes ya cerrado y con aviso.
